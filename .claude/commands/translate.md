Use the **translate-agent** and **translation skill** for high-quality translation.

## Task

Translate: $ARGUMENTS

## Process

1. **Understand context**:
   - Identify source and target languages
   - Determine content type (technical, marketing, legal, casual)
   - Understand audience and formality level
   - Check for style guidelines

2. **Build glossary**:
   - Identify key terms needing consistency
   - Check existing translations
   - Create/update term glossary
   - Document translation choices

3. **Translate systematically**:
   - Work section by section
   - Preserve meaning first, then style
   - Adapt idioms and cultural references
   - Maintain tone and formality
   - Use glossary for consistency
   - Preserve formatting (headings, bullets, code, links)

4. **Adapt culturally**:
   - Adjust directness level for target culture
   - Handle hierarchical language (formal/informal pronouns)
   - Apply gender and inclusivity considerations
   - Localize numbers, dates, measurements
   - Adapt cultural references appropriately

5. **Quality assurance**:
   - Apply comprehensive checklist:
     - Meaning accurate throughout
     - No omissions or additions
     - Terminology consistent
     - Tone and style appropriate
     - Grammar and spelling correct
     - Formatting preserved
     - Cultural adaptation appropriate
   - Check for common errors (false friends, gender agreement, verb tenses)
   - Provide alternatives for ambiguous phrases

6. **Deliver with context**:
   - Present translated content
   - Include translation glossary
   - Document important decisions
   - Note cultural adaptations
   - Provide quality metrics

## Output Format

Provide a complete translation package including:
- **Translation Summary**: Languages, type, formality, date, word count
- **Translated Content**: Full translation with all formatting preserved
- **Translation Glossary**: Source → Target with context and notes
- **Translation Notes**: Important decisions, cultural adaptations, ambiguities
- **Quality Metrics**: Completeness, consistency, confidence, cultural fit

## Quality Standards

- Accurate: Meaning preserved exactly
- Natural: Sounds native in target language
- Clear: Easy to understand
- Appropriate: Matches audience and context
- Consistent: Glossary applied throughout
- Transparent: Decisions documented, alternatives provided
