## Detailed Workflow Descriptions

### Research & Synthesis

**Use when you need to**:
- Research any topic systematically
- Conduct literature reviews
- Evaluate technologies or tools
- Understand market trends
- Analyze user pain points
- Gather evidence for decisions

**Time Savings**: 8 hours → 1 hour (8x faster)

**Example Commands**:
```bash
/workflows:research-synthesis "Best practices for remote team collaboration"
/workflows:research-synthesis "Market size and growth trends for AI in healthcare"
/workflows:research-synthesis "Comparison of React vs Vue for enterprise applications"
```

**What You Get**:
- Executive summary with key findings
- Evidence table with 10+ credible sources
- Confidence levels for each finding
- Patterns and insights
- Actionable recommendations
- Limitations and gaps

**Best For**: PMs, researchers, executives, developers (tech decisions)

---

### Content Creation

**Use when you need to**:
- Write blog posts or articles
- Create documentation
- Draft reports or white papers
- Write case studies
- Create social media content
- Develop teaching materials

**Time Savings**: 2 hours → 30 minutes (4x faster)

**Example Commands**:
```bash
/workflows:content-creation "Blog post: 5 Ways to Improve Team Productivity"
/workflows:content-creation "Technical documentation for API authentication"
/workflows:content-creation "Case study: How we reduced server costs by 60%"
```

**What You Get**:
- Well-structured content with clear flow
- Professional tone and style
- Proper headings and organization
- Introduction, body, conclusion
- Ready for customization
- SEO-friendly (for web content)

**Best For**: Marketers, content writers, PMs, researchers, developers (docs)

---

### Professional Email

**Use when you need to**:
- Send any professional email
- Follow up after meetings
- Request approvals or decisions
- Thank colleagues or clients
- Decline requests politely
- Provide status updates

**Time Savings**: 30 minutes → 5 minutes (6x faster)

**Example Commands**:
```bash
/workflows:professional-email "Request PTO approval from manager for 2 weeks in July"
/workflows:professional-email "Thank client for choosing our proposal"
/workflows:professional-email "Follow up with prospect after demo meeting"
```

**What You Get**:
- Professional subject line
- Appropriate greeting and tone
- Clear message with context
- Specific action items
- Professional closing
- Ready to personalize and send

**Best For**: Everyone! Most universally useful workflow

---

### Competitive Analysis

**Use when you need to**:
- Understand competitive landscape
- Analyze market positioning
- Compare features or products
- Develop pricing strategy
- Create SWOT analysis
- Identify market gaps

**Time Savings**: 12 hours → 2.5 hours (5x faster)

**Example Commands**:
```bash
/workflows:competitive-analysis "CRM platforms for small businesses"
/workflows:competitive-analysis "Our competitive position in enterprise SaaS market"
/workflows:competitive-analysis "Marketing automation tools comparison"
```

**What You Get**:
- Competitor profiles with strengths/weaknesses
- Feature comparison matrix
- Pricing analysis
- SWOT for each competitor
- Positioning map
- Strategic recommendations (Defend/Attack/Expand/Watch)

**Best For**: PMs, executives, marketers, sales (battle cards)

---

### Proposal & Pitch

**Use when you need to**:
- Write business proposals
- Create pitch decks or memos
- Respond to RFPs
- Request budget or resources
- Apply for grants or funding
- Propose partnerships

**Time Savings**: 8 hours → 2.5 hours (3x faster)

**Example Commands**:
```bash
/workflows:proposal-pitch "Budget request for hiring 3 engineers in Q2"
/workflows:proposal-pitch "Proposal to implement new CRM system"
/workflows:proposal-pitch "Partnership proposal with enterprise software vendor"
```

**What You Get**:
- Executive summary
- Problem statement
- Proposed solution
- ROI and value proposition
- Implementation plan
- Risk mitigation
- Clear call-to-action

**Best For**: PMs, sales, executives, researchers (grants)

---

### Meeting Preparation

**Use when you need to**:
- Prepare for client meetings
- Prep board presentations
- Plan team meetings
- Ready for stakeholder reviews
- Prepare for performance reviews
- Get ready for QBRs

**Time Savings**: 2 hours → 30 minutes (4x faster)

**Example Commands**:
```bash
/workflows:meeting-prep "Quarterly business review with top enterprise client"
/workflows:meeting-prep "Board meeting presentation on Q3 strategy"
/workflows:meeting-prep "Discovery call with new prospect evaluating our platform"
```

**What You Get**:
- Meeting brief and context
- Stakeholder profiles (roles, priorities)
- Strategic talking points
- Anticipated questions with answers
- Materials checklist
- Success criteria and next steps

**Best For**: Sales, PMs, executives, anyone with important meetings

---

### Code Review

**Use when you need to** (developers):
- Review code for quality
- Security audits
- Architecture reviews
- Pre-deployment checks
- Legacy code assessment
- Onboarding code walkthroughs

**Time Savings**: 1 hour → 10 minutes (6x faster)

**Example Commands**:
```bash
/workflows:code-review "src/authentication/"
/workflows:code-review "api/payment-processing/"
/workflows:code-review "components/user-dashboard/"
```

**What You Get**:
- Security vulnerability analysis
- Code quality assessment
- Architecture pattern review
- Performance considerations
- Specific actionable recommendations
- Test coverage evaluation

**Best For**: Developers, engineering managers, tech leads

---

### Feature Development

**Use when you need to** (developers):
- Build new features systematically
- Major refactoring projects
- System design
- Technical spike planning
- Architecture decisions
- Production deployments

**Time Savings**: Variable (3-5x faster overall)

**Example Commands**:
```bash
/workflows:feature-development "User authentication with SSO support"
/workflows:feature-development "Real-time collaboration feature"
/workflows:feature-development "Payment processing with Stripe integration"
```

**What You Get**:
- 9-phase systematic process
- Planning before coding
- Quality gates at each step
- Test coverage included
- Documentation built-in
- Production-ready approach

**Best For**: Developers, technical PMs

## Mix & Match Workflows

**Most tasks use multiple workflows together:**

### Example 1: Product Launch
1. **Research & Synthesis** - Market trends and user needs
2. **Competitive Analysis** - Competitive landscape
3. **Content Creation** - Launch blog post and docs
4. **Professional Email** - Announce to customers
5. **Meeting Preparation** - Launch review with leadership

**Total Time Saved**: 25+ hours

---

### Example 2: Grant Application
1. **Research & Synthesis** - Current state of research area
2. **Competitive Analysis** - Similar research being done
3. **Proposal & Pitch** - Grant proposal draft
4. **Professional Email** - Follow-up with program officer

**Total Time Saved**: 22+ hours

---

### Example 3: Sales Deal
1. **Research & Synthesis** - Prospect company and industry
2. **Meeting Preparation** - Discovery call prep
3. **Proposal & Pitch** - Custom proposal
4. **Professional Email** - Follow-ups throughout process

**Total Time Saved**: 20+ hours per deal

## Still Not Sure?

### Ask Yourself These Questions:

**Q1: What's your deliverable?**
- Written document → Content Creation
- Email → Professional Email
- Presentation deck → Proposal & Pitch
- Research report → Research & Synthesis
- Market analysis → Competitive Analysis

**Q2: Who's your audience?**
- Internal team → Meeting Prep, Email, Content
- Customers → Email, Proposal, Content
- Executives → Proposal, Competitive, Meeting Prep
- General public → Content Creation

**Q3: What's your goal?**
- Learn/understand → Research & Synthesis
- Persuade/convince → Proposal & Pitch
- Inform/update → Professional Email, Content
- Analyze/compare → Competitive Analysis
- Prepare/plan → Meeting Preparation

**Q4: How much time do you have?**
- 30 seconds → Professional Email
- 1-3 minutes → Meeting Prep, Code Review
- 3-5 minutes → Research, Competitive, Proposal, Content
- 5-15 minutes → Feature Development

## Pro Tips

### 1. Start Simple
If you're new, start with **Professional Email** (easiest, fastest).

### 2. Combine Workflows
Most projects benefit from multiple workflows. Research → Proposal → Email is a common pattern.

### 3. Iterate
Don't expect perfection on first try. Run workflow, review, adjust description, run again.

### 4. Be Specific
Better command = better output. Include context, audience, tone.

### 5. Track Success
Use the [Time Savings Tracker](time-savings-tracker.md) to see which workflows save you the most time.
