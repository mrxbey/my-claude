# Code Review Workflow Example

## What This Example Shows

- **Input**: Code directory or file path to review
- **Process**: 6-phase code review workflow
- **Output**: Comprehensive code review report with actionable recommendations
- **Time Saved**: 60 minutes → 10 minutes = **6x faster**

## Workflow Execution

**Phase 1: Security Analysis** (2 min) - Scan for vulnerabilities, authentication flaws, injection risks
**Phase 2: Code Quality Assessment** (2 min) - Check readability, maintainability, complexity
**Phase 3: Architecture Review** (2 min) - Evaluate patterns, separation of concerns, scalability
**Phase 4: Performance Analysis** (1 min) - Identify bottlenecks, optimization opportunities
**Phase 5: Test Coverage Review** (2 min) - Assess test quality and coverage gaps
**Phase 6: Recommendations** (1 min) - Prioritize findings, provide specific fixes

**Total**: ~10 minutes | **Manual**: 60+ minutes | **Savings**: 6x

## Output Quality

[OUTPUT.md](OUTPUT.md) shows a professional code review including:
- Security vulnerability assessment
- Code quality scores
- Architecture feedback
- Performance recommendations
- Test coverage analysis
- Prioritized action items with code examples

## Real Impact

**Engineering team**: Code review time reduced from 60 min to 10 min per PR. Security issues detected 40% earlier. Review consistency improved across team.

## Use Cases

**Before deployment**: Catch issues before production
**Security audits**: Systematic vulnerability scanning
**Onboarding**: Help new developers understand codebase standards
**Technical debt**: Identify refactoring opportunities
**Pre-commit**: Quick quality gates before merge
