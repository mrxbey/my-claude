# Competitive Analysis Input

## Command Used

```bash
/workflows/competitive-analysis "Project management tools for remote-first teams (<50 employees)"
```

## Context Provided

"We're a project management software company targeting remote-first teams of <50 employees. Need to understand competitive landscape to refine our positioning and roadmap. Focus on tools specifically designed for remote work (not general PM tools adapted for remote). Looking for strategic insights on where to compete and where to differentiate."

This simple context produced a comprehensive 20-page competitive analysis with:

- SWOT analyses
- Strategic positioning recommendations
