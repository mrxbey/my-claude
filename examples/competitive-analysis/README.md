# Competitive Analysis Workflow Example

This example demonstrates the `/workflows/competitive-analysis` workflow in action.

## What This Example Shows

- **Input**: Market/product to analyze
- **Process**: 6-phase systematic competitive analysis
- **Output**: Comprehensive strategic analysis with actionable recommendations
- **Time Saved**: 12 hours → 2-3 hours = **4-6x faster**

## The Challenge

Manual competitive analysis is time-consuming and scattered:
- ❌ Hours researching each competitor
- ❌ Inconsistent comparison criteria
- ❌ Difficulty synthesizing insights
- ❌ 10-15 hours for comprehensive analysis

**Without systematic process**: Incomplete analysis, missed insights, delayed decisions

## The Solution

Competitive analysis workflow provides:
- ✅ Systematic competitor identification
- ✅ Structured comparison frameworks
- ✅ SWOT analysis for each competitor
- ✅ Strategic positioning and recommendations
- ✅ Comprehensive analysis in 2-3 hours

## Workflow Execution

### Phase 1: Competitor Identification (20 minutes)
- Identified 3 direct competitors
- Identified 2 indirect competitors
- Noted 1 emerging threat
- Categorized by competitive intensity

### Phase 2: Information Gathering (45 minutes)
- Researched features, pricing, market position for each
- Gathered data from: websites, reviews, industry reports, social media
- Compiled competitor profiles with 40+ data points

### Phase 3: Comparison Framework (30 minutes)
- Built feature comparison matrix (8 key features × 6 competitors)
- Analyzed pricing across tiers
- Compared market position and growth trajectories

### Phase 4: SWOT Analysis (30 minutes)
- Conducted comprehensive SWOT for each major competitor
- Identified strategic patterns
- Noted opportunities and threats

### Phase 5: Strategic Positioning (20 minutes)
- Created positioning map (price vs features)
- Analyzed differentiation opportunities
- Identified white space in market

### Phase 6: Strategic Recommendations (15 minutes)
- Generated Defend/Attack/Expand/Watch recommendations
- Prioritized by impact and effort
- Created action timeline

**Total Time**: ~2.5 hours
**Manual Time**: 12-15 hours
**Time Savings**: 4-6x faster
