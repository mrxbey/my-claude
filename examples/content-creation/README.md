# Content Creation Workflow Example

This example demonstrates the `/workflows/content-creation` workflow in action.

## What This Example Shows

- **Input**: Simple content brief
- **Process**: 7-phase content development workflow
- **Output**: Publication-ready 1,500-word blog post
- **Time Saved**: 2 hours manual writing → 30 minutes with workflow = **4x faster**

## The Task

**Content Brief**: "Blog post about how AI workflows transform knowledge worker productivity"

**Target Audience**: Marketing managers, product managers, executives
**Purpose**: Inform and convert (drive trial signups)
**Tone**: Professional but conversational

## Workflow Execution

### Phase 1: Audience & Purpose Definition (3 minutes)
- Defined audience (mid-senior level, non-technical)
- Clarified purpose (inform + convert)
- Set success metrics (shares, trial signups)
- Determined tone (professional-conversational, benefit-focused)

### Phase 2: Research & Outline (6 minutes)
- Researched productivity statistics, AI adoption trends
- Identified 5 main points (time savings, quality, consistency, collaboration, ROI)
- Created detailed outline with hook, body structure, CTA
- Gathered supporting stats and examples

### Phase 3: Draft Creation (10 minutes)
- Wrote attention-grabbing hook (pain point)
- Crafted introduction previewing benefits
- Wrote 5 body sections with evidence
- Added compelling conclusion and CTA

### Phase 4: Style & Tone Refinement (4 minutes)
- Read-aloud test for flow
- Varied sentence length for engagement
- Added conversational elements
- Formatted for scannability (bullets, subheadings)

### Phase 5: Proofreading (3 minutes)
- Fixed grammar and spelling
- Improved clarity
- Ensured terminology consistency
- Tightened prose (removed 200 words)

### Phase 6: Compliance & Brand Check (2 minutes)
- Verified brand voice consistency
- Checked content policy compliance
- Optimized for SEO (keywords, meta description)

### Phase 7: Final Polish (2 minutes)
- Tested 8 headline variations, selected best
- Strengthened opening hook
- Enhanced subheadings for scannability
- Refined CTA for conversion

**Total Time**: ~30 minutes
**Manual Time**: 2-3 hours
**Time Savings**: 4-6x faster
