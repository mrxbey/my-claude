# Professional Email Input Examples

This document shows the input contexts used to generate the 5 email examples in OUTPUT.md.

---

## Email 1: Formal Executive Request

### Command
```bash
/workflows/professional-email "Request budget approval from CFO"
```

### Context Provided
"Need to request $50K budget approval from CFO (Sarah Chen) for Q4 marketing campaign. She's data-driven and extremely busy. We've done similar campaigns before with 3x ROI. Need approval by Friday to lock in vendor pricing. She prefers emails under 150 words."

---

## Email 2: Professional Peer Collaboration

### Command
```bash
/workflows/professional-email "Coordinate with project manager on timeline alignment"
```

### Context Provided
"Need to align with Michael (PM) on project timeline. Our teams have dependencies - we need their API done by Dec 1 for our feature launch Dec 15. Want collaborative tone, not demanding. We've worked together successfully before. Looking for mutual agreement on dates."

---

## Email 3: Diplomatic Difficult Conversation

### Command
```bash
/workflows/professional-email "Address missed deadline with vendor"
```

###Context Provided
"Vendor (TechCorp) missed delivery deadline (was due Monday, now Thursday). This delays our launch. Need to address professionally without burning bridge - we'll work with them again. Want acknowledgment of impact, revised timeline, and assurance it won't happen again. Maintain relationship but be clear about consequences."

---

## Email 4: Direct Urgent Request

### Command
```bash
/workflows/professional-email "Urgent request for client data"
```

### Context Provided
"Need customer usage data from Jessica (Customer Success) ASAP for board presentation tomorrow at 2 PM. Specifically need: monthly active users, feature adoption rates, NPS scores. She's usually responsive but sometimes forgets follow-ups. Clear deadline, specific asks, appreciate urgency."

---

## Email 5: Friendly Thank You

### Command
```bash
/workflows/professional-email "Thank colleague for presentation help"
```

### Context Provided
"Want to thank David for helping with my sales presentation last week. He spent 2 hours helping me refine messaging and gave great feedback. The presentation went really well - closed the deal. Want genuine appreciation, specific about what helped, mention the outcome. We're peers, friendly relationship."

---

## That's It!

Each simple context (2-3 sentences) produces a professionally-crafted email in ~5 minutes.

See [OUTPUT.md](OUTPUT.md) for the resulting emails.
