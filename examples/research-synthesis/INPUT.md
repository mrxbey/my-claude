# Research Synthesis Input

## Command Used

```bash
/workflows/research-synthesis "What are the best AI agent frameworks for enterprise applications in 2025?"
```

## Context Provided

"We're evaluating AI agent frameworks for our enterprise product development. Need to understand the current landscape, which frameworks are production-ready, their strengths/weaknesses, and which would be best for enterprise use cases involving multi-agent collaboration, workflow orchestration, and integration with existing systems."

## That's It!

The workflow took this simple input and produced a comprehensive 12-page research report with:
- 12 sources evaluated
- 45+ evidence points
- Systematic analysis
- Clear recommendations
- Confidence levels for each finding
