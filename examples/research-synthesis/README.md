# Research & Synthesis Workflow Example

This example demonstrates the `/workflows/research-synthesis` workflow in action.

## What This Example Shows

- **Input**: Simple research question
- **Process**: 6-phase systematic research workflow
- **Output**: Professional research report with sources, evidence, and recommendations
- **Time Saved**: 8 hours manual research → 1 hour with workflow = **8x faster**

## The Task

**Research Question**: "What are the best AI agent frameworks for enterprise applications in 2025?"

**Context**: Product team evaluating AI agent frameworks for enterprise product development

## Workflow Execution

### Phase 1: Question Clarification (3 minutes)
- Restated question and broke into 4 sub-questions
- Defined scope (enterprise-ready, production-grade, 2024-2025)
- Set success criteria (comparison table, recommendations)

### Phase 2: Source Discovery (8 minutes)
- Identified 12 relevant sources
- Mix of: Technical documentation, industry reports, developer communities, comparative analyses
- Evaluated source credibility

### Phase 3: Information Extraction (15 minutes)
- Created evidence table with 45+ data points
- Mapped findings to sub-questions
- Assessed evidence quality (strong/moderate/weak)

### Phase 4: Synthesis & Analysis (12 minutes)
- Identified 5 key patterns
- Resolved contradictions between sources
- Generated strategic insights
- Assigned confidence levels

### Phase 5: Evidence Validation (8 minutes)
- Cross-checked claims across multiple sources
- Detected potential biases
- Verified logical consistency
- Rated overall credibility: 8.5/10

### Phase 6: Report Generation (14 minutes)
- Structured professional research report
- Added citations for all claims
- Included limitations and further research needs

**Total Time**: ~60 minutes
**Manual Time**: 8-10 hours
**Time Savings**: 8-10x faster
